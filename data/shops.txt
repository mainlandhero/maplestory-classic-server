# NPC shops - Victoria Island, complete as of 2026-08-19
#
# AUTHORED DATA, NOT GENERATED. This file is the one place in the repo that holds game
# content we wrote down rather than extracted, and it is deliberately NOT in gm-handbook/ -
# that directory is generated, gitignored and never hand-edited. This is the opposite: it is
# source, it is committed, and nothing regenerates it.
#
# Gathered by the owner from the live game, 2026-08-19, and every shop is labelled "COT2 prices"
# there. It is the only source for these numbers: shop contents are NOT in the client's WZ -
# see STATUS.md goal F, where that was checked three ways with a control each.
#
# ## Prices
#
# The number here is the BUY price - what the NPC charges.
#
# The SELL price is a different thing and comes from the client: `Item.wz <id>/info/price`.
# The owner, 2026-08-19: "The prices client side most likely represents sell prices."
# The evidence beside that reading: every consumable checked is exactly 10.00x its WZ price
# (Red Potion 5 -> 50, Blue Potion 22 -> 220, Meat 8 -> 80, Lemon 15 -> 150 - nine of nine),
# but Pet Food is 15 -> 35, so the ratio is NOT a constant and buy prices cannot be derived.
# They have to be authored, which is what this file is for.
#
# ## Format
#
#   shop: <npc name> | <role> | <map>
#   <tab><item name><tab><price>[<tab>rank]
#
# Item NAMES, not ids, on purpose: the ids come from the client's own String.wz name table
# (`gm-handbook/items.txt`), so a name that does not resolve is a transcription error this
# file can be checked for rather than a wrong item shipped silently.
#
# `rank` is the citizenship/reputation gate shown in the live UI ("Town Resident+"). The
# client's quest data has `citizenshipTown` and `citizenshipGrade` Check keys, so the concept
# is real in this client; the mapping from these labels to grade numbers is NOT established.
# Items with a rank are recorded with it and must not be sold to a character below it.
